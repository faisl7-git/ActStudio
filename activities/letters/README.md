# تحدي الحروف

نشاط تنافسي بين الفرق: يختار الفريق حرفًا من اللوحة، فيظهر سؤال إجابته
تبدأ بذلك الحرف. الحرف يتلوّن بلون الفريق عند الإجابة الصحيحة، ويُغلق
بالرمادي عند الخطأ.

## الحالة

نسخة عاملة ومتصلة ببنك الأسئلة الخارجي. يحمّل النشاط إعداداته من
`config.json`، ثم يقرأ ملف `letters.json` الموافق للمرحلة الدراسية.
لا توجد نسخة أسئلة مضمّنة داخل `app.js`.

## بنك الأسئلة

| المرحلة داخل النشاط | ملف البنك |
|---|---|
| ابتدائي 1–3 | `questions/primary_1_3/letters.json` |
| ابتدائي 4–6 | `questions/primary_4_6/letters.json` |
| متوسط | `questions/middle/letters.json` |
| ثانوي | `questions/secondary/letters.json` |

يحتوي كل ملف على 75 سؤالًا، أي 300 سؤال في المجموع. المجال محفوظ في
الحقل `category`، والمرحلة يحددها مسار الملف.

## التشغيل

يجب تشغيل المشروع عبر استضافة ويب أو خادم محلي لأن المتصفح يمنع
`fetch` عند فتح الصفحة مباشرة عبر `file://`.
