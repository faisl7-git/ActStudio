# القالب

القالب الفارغ الذي يُنسخ عند إنشاء أي نشاط جديد. لا يُشغَّل مباشرة.

## طريقة الاستخدام

1. انسخ هذا المجلد باسم النشاط الجديد داخل `activities/`.
2. عبّئ `config.json`: الاسم، الثيم، مسار الأسئلة.
3. اكتب المنطق في `app.js` والأنماط الخاصة في `style.css`.
4. استدعِ المشترك من `shared/` بدل تكراره.
5. حدّث هذا الملف بشرح النشاط.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | صفحة النشاط، وتربط ملفات shared ثم الملفات الخاصة |
| `style.css` | أنماط النشاط فقط |
| `app.js` | منطق النشاط |
| `config.json` | إعدادات النشاط |
| `README.md` | هذا الملف |
