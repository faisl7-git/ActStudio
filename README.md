# ActStudio — أنشطة

بنية المشروع الموحّدة لمنصّة **أنشطة**.

هذا المجلد يحتوي على **الهيكل فقط**. لم يُنقل إليه أي ملف من الأنشطة الحالية،
ولم يُعدَّل أي نشاط موجود خارجه. جميع الملفات هنا فارغة أو placeholders
في انتظار التعبئة في مراحل لاحقة.

## وظيفة كل مجلد

### `assets/`
الأصول الثابتة التي تشترك فيها كل الأنشطة. لا تحتوي على كود.

| المجلد | الوظيفة |
|---|---|
| `logos/` | شعار «أنشطة» بصيغه المختلفة: الرئيسي، العكسي، الأفقي، أيقونة التطبيق |
| `fonts/` | ملفات الخطوط `.woff2` — Tajawal وIBM Plex Sans Arabic — لتضمينها محليًا بلا إنترنت |
| `icons/` | أيقونات الواجهة والملفات (PDF، Word، Canva، QR…) بصيغة SVG |
| `sounds/` | المؤثرات الصوتية إن استُبدلت لاحقًا بملفات جاهزة بدل التوليد البرمجي |
| `images/` | الصور والرسوم والخلفيات وأغلفة المنتجات |
| `themes/` | ملفات تعريف الثيمات (متغيّرات ألوان لكل ثيم) |

### `shared/`
الكود الذي تستدعيه كل الأنشطة بدل تكراره داخل كل ملف.

| الملف | الوظيفة |
|---|---|
| `css/base.css` | التصفير، الخطوط، الشبكة، الطباعة، الأساسيات المشتركة |
| `css/components.css` | مكوّنات الواجهة المتكرّرة: الأزرار، البطاقات، الحبوب، الويزارد، المؤقت |
| `css/theme.css` | متغيّرات هوية أنشطة: الألوان، الزوايا، الظلال، الخطوط |
| `js/helpers.js` | دوال عامة: الخلط، التطبيع العربي، تنسيق الوقت، الهروب من HTML |
| `js/audio.js` | محرك الصوت: التوليد، كتم الصوت، التعامل الآمن مع فشل الصوت |
| `js/storage.js` | التخزين المحلي: الأسئلة المستخدمة حديثًا، تفضيلات المعلم |
| `js/ui.js` | عناصر الواجهة المشتركة: الويزارد، بطاقات الفرق، القصاصات، النوافذ |

### `questions/`
بنوك الأسئلة مفصولة تمامًا عن الكود. أربع مراحل دراسية، وداخل كل مرحلة
اثنا عشر مجالًا بصيغة JSON. تعديل الأسئلة لا يتطلّب لمس أي سطر برمجي.

المراحل: `primary_1_3` · `primary_4_6` · `middle` · `secondary`

المجالات في كل مرحلة: `sports` · `history` · `science` · `islamic` ·
`geography` · `technology` · `brands` · `riddles` · `capitals` ·
`animals` · `plants` · `mixed`

جميع الملفات حاليًا `[]` فارغة.

### `activities/`
كل نشاط مستقل بذاته في مجلد واحد، وبنفس التركيبة الخمسية:

| الملف | الوظيفة |
|---|---|
| `index.html` | صفحة النشاط |
| `style.css` | أنماط خاصة بالنشاط فقط، فوق `shared/css` |
| `app.js` | منطق النشاط |
| `config.json` | إعدادات النشاط: الاسم، الإصدار، الثيم، مسار الأسئلة، وضع المعلم |
| `README.md` | شرح النشاط وطريقة تشغيله |

`template/` هو القالب الفارغ الذي يُنسخ عند إنشاء أي نشاط جديد.

### `docs/`
التوثيق الفني. يبدأ بـ `project-structure.md` الذي يشرح كيف ستعمل
القطع مع بعضها.

## ملاحظة على المجلدات الفارغة

مجلدات `assets/*` تحتوي على ملف `.gitkeep` واحد لكل مجلد، لأن أنظمة
الملفات وأنظمة إدارة الإصدارات لا تحفظ المجلدات الفارغة. احذفها متى
أضفت أول ملف حقيقي.

## الحالة

| العنصر | الحالة |
|---|---|
| الهيكل | مكتمل |
| ملفات الأسئلة | فارغة `[]` |
| ملفات `shared` | رؤوس توضيحية فقط، بلا كود |
| ملفات الأنشطة | placeholders |
| ربط الأنشطة الحالية | لم يبدأ |
